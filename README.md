# AIverse – Discover the Power of Artificial Intelligence

### Your Gateway to Exploring the World of AI Tools
AIverse is an AI tools discovery platform designed to bring powerful Artificial Intelligence resources together in one convenient place. It helps students, developers, professionals, content creators, and businesses discover tools that simplify tasks, improve productivity, encourage creativity, and support innovation.
Instead of spending hours searching across multiple websites, users can explore AI tools through a centralized platform with search, category filters, pricing filters, descriptions, and direct access to official websites.
**Discover. Explore. Innovate. With AIverse.**
---
## Key Highlights
- **Smart Tool Discovery** – Explore AI tools through an organized directory.- **Category-Based Exploration** – Find tools based on different use cases.- **Pricing-Based Filtering** – Discover free and paid AI solutions.- **Personalized Favorites** – Save preferred tools for quick access.- **Responsive Experience** – Access the platform across desktop, tablet, and mobile devices.- **Fast and Simple Navigation** – Explore AI resources through a clean interface.- **Direct Tool Access** – Visit the official websites of listed AI tools.

## Getting Started
Follow these steps to run the project locally.
### Prerequisites
- Node.js- npm- Git
### Installation
**1. Clone the repository**
```bashgit clone https://github.com/YOUR-USERNAME/AIverse.git```
**2. Navigate to the project directory**
```bashcd AIverse```
**3. Install dependencies**
```bashnpm install```
**4. Start the development environment**
```bashnpm run dev```
**5. Open the application**
Visit:
```texthttp://localhost:5173```
The backend API runs on:
```texthttp://localhost:5000```
---
## Backend API Endpoints
| Method | Endpoint | Description ||---|---|---|| GET | `/api/health` | Check backend server status || GET | `/api/categories` | Retrieve available categories || GET | `/api/tools` | Retrieve AI tools || GET | `/api/tools/:id` | Retrieve an individual tool |
