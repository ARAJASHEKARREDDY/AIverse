# AIverse – Discover the Power of Artificial Intelligence

**Your Gateway to Exploring the World of AI Tools**

AIverse is an AI tools discovery platform that brings powerful Artificial Intelligence resources together in one convenient place. It helps students, developers, professionals, content creators, and businesses discover tools that simplify tasks, improve productivity, encourage creativity, and support innovation.

Instead of spending hours searching across multiple websites, users can explore AI tools through a centralized platform featuring search functionality, category filters, pricing filters, tool descriptions, and direct access to official websites.

**Discover. Explore. Innovate. With AIverse.**

---

## ✨ Key Highlights

- **Smart Tool Discovery:** Explore AI tools through an organized directory.
- **Category-Based Exploration:** Find tools based on different use cases.
- **Pricing-Based Filtering:** Discover free and paid AI solutions.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/AIverse.git
```

**2. Navigate to the project directory**

```bash
cd AIverse
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development environment**

```bash
npm run dev
```

**5. Open the application**

Visit the following address in your browser:

```text
http://localhost:5173
```

The backend API runs at:

```text
http://localhost:5000
```

## 🔗 Backend API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Check backend server status |
| GET | `/api/categories` | Retrieve available categories |
| GET | `/api/tools` | Retrieve AI tools |
| GET | `/api/tools/:id` | Retrieve an individual tool |
